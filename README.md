# زاد الخير

تطبيق عربي لقراءة القرآن الكريم والاستماع إليه والتفسير الوجيز والختمات الجماعية ومواقيت الصلاة.

الموقع: <https://zad-alkhair.net/> · دليل المشغّل: <https://zad-alkhair.net/quran/player-guide/>

## التشغيل والتطوير

يلزم Node.js 22.13 أو أحدث. لا توجد حزم npm مطلوبة أو خطوة تثبيت للواجهة.

```sh
npm run dev
npm run build
npm run check
```

المعاينة على `http://127.0.0.1:4173/`. يمكن ضبط `PORT` و`HOST` من البيئة. المعاينة خادم ملفات محلي، وتحتوي الواجهة على إعداد اتصال قاعدة الإنتاج؛ لا تُجرِ تغييرات تجريبية على ختمات حقيقية.

## أين نعدّل؟

| الجزء | المصدر المعتمد |
| --- | --- |
| الرئيسية والختمات ومواقيت الصلاة | `src/home/`: قالب الصفحة والتصميم وأقسام JS حسب المسؤولية |
| المصحف ومشغّل التلاوة | `src/reader/`: التفسير والمصحف ومصادر الصوت والتحكم والقائمة |
| بيانات السور والأجزاء وصفحات القراء | `src/discovery/catalog.json` |
| قوالب صفحات الاكتشاف | `scripts/build-seo-pages.cjs` و`src/discovery/*.html` |
| المظهر المشترك لصفحات الاكتشاف | `seo-pages.css` و`seo-pages.js` |
| دليل الفيديو | `quran/player-guide/` |
| العمل دون اتصال | `sw.js` |
| التفسير وبيانات مصادر الصوت | `data/tafsir/al-wajeez/` و`data/maher-timing-source.json` |
| صور المشاركة ومصادرها | `social/` |
| سكربتات البناء والتحقق | `scripts/` |
| الوظائف الخلفية | `supabase/functions/` |
| سجل ترحيلات قاعدة البيانات المنشورة | `supabase/migrations/` |

`app.js` في كل من home وreader هو ترتيب أقسام المصدر؛ يحتوي علامات `@include` لأقسام مثل `prayer.js` و`audio-sources.js`. تُجمع عند البناء في النطاق وترتيب التنفيذ نفسيهما، دون طلبات شبكة إضافية. عدّل القسم المعني؛ لا تنشئ ملف JS غير مربوط بترتيب الأقسام، لأن الفحص سيرفضه.

`index.html` و`reader.html` وصفحات السور والأجزاء والقراء ملفات ناتجة محفوظة للنشر المباشر. عدّل المصادر ثم شغّل `npm run build`؛ لا تعدّل الناتج وحده. يبقي البناء CSS وJavaScript داخل وثيقتي التطبيق للحفاظ على التشغيل المستقل وترتيب التنفيذ وحماية التحديث دون اتصال.

النشر الحالي عبر Cloudflare Pages من فرع `main`، وليس عبر خدمة Sites. لا تغيّر النطاق أو أسماء مخازن المتصفح لمجرد إعادة التنظيم.
