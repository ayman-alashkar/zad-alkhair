## حدود التحقق وما يحتاج متابعة

- نجحت اختبارات الوحدة والسلوك وبيانات SEO والتفسير. الاختبارات الحالية لا تعادل اختبارًا على كل جهاز فعلي.

- صياغة TypeScript فُحصت دون تنفيذ وظائف Telegram؛ لم تُرسل رسائل ولم تتغير القاعدة أو صلاحياتها.
- تحذيرات Supabase المتعلقة بوظائف SECURITY DEFINER وRLS محفوظة ومشروحة في وثيقة الخلفية. يلزم تدقيق تفويض كل RPC؛ لا يجوز إلغاء الصلاحيات دفعة واحدة.
- سجل migrations لا يشمل مخطط إنشاء القاعدة الأولى؛ اختبار استعادة كامل في قاعدة تطوير ما زال مطلوبًا.
- CSS ومنطق القارئ ما زالا يحتويان طبقات تعديلات تاريخية. الفصل أنشأ مصدرًا واضحًا؛ توحيد القواعد المتراكمة وتقسيم السلوك إلى وحدات أصغر يحتاجان اختبارات تكامل وعرض قبل تغييرهما.
